# neural-network

A tiny neural network written in Rust, from scratch (no ML libraries). Built this just to use as an example to begin building on at some point. Definitely inspired by Karparthy and will see what I can train with it. 

It's a single-layer perceptron: two inputs in, one number out (0 to 1).


## Run it

```
cargo run
```

This trains on [data.csv](../data.csv) and prints a prediction for each test row.
